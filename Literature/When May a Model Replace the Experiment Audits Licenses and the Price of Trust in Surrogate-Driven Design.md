> [!abstract] 摘要直译
> 化学、材料科学和机器学习中的设计活动有一个共同瓶颈：判断候选方案的真实质量需要昂贵评估，例如实验、第一性原理模拟或完整训练。机器学习代理模型不仅用于提出候选，也越来越多地被用于给候选打分，甚至将自己的预测反馈到搜索过程中，仿佛这些预测就是测量结果。本文通过数学分析，并在三个具有完整真实标注的设计任务上验证，回答这种做法何时安全、安全证书需要付出什么成本，以及何时能够真正节省成本。作者证明，预测准确性不能作为信任依据：接近完美的 R² 仍可能对应最差的候选选择；筛选 N 个候选会使最终选中点的过度预测产生可量化的“选择税”。安全性来自一条架构规则：预测可以不受限制地用于提案和训练，但每一项认证结论都必须建立在真实评估上。随后，论文给出模型充当 Oracle 的最小条件——保持排序而非数值准确；提出面向实际选择流程的审计，并证明其查询复杂度最优；最后指出代理替代真实评估能否降低认证成本取决于目标：无共享结构的固定菜单选择中不能节省，而生成式搜索中若审计通过则可能获得与筛选规模相关的成本优势。实验覆盖三种设计任务、432 次代理拟合；部署感知审计统计量与搜索表现的 Spearman 相关系数为 0.89–0.99，实际 120 轮审计预算下为 0.80–0.94；R² 与部署遗憾的相关性最低降至 0.33。经审计筛选在摊销训练和审计成本后，真实评估成本降低约 25 倍；在包含前期成本的一次 100 个设计活动中仍节省约 14 倍。

## 研究问题与问题定义

设计任务通常是候选生成便宜、真实性能评估昂贵。候选可以是材料配方、催化剂、蛋白结合体或神经网络架构；Oracle 可以是实验、密度泛函理论计算、分子对接或完整模型训练。论文区分两类部署目标：**固定菜单选择**，从给定有限候选列表中认证最优者；**生成式搜索**，从可廉价生成的候选分布中找到真实性能超过质量门槛的设计，而不要求证明全局最优。

设真实目标函数为 f，代理为 f̂，候选池为 C。代理冠军为 x̂=argmax f̂(x)，简单遗憾（simple regret）为：

$$
r_C=\max_{x\in C}f(x)-f(\hat x)
$$

它衡量代理冠军相对于候选池真实最优者损失了多少真实性能。过度预测（false optimism）定义为 e⁺(x)=[f̂(x)−f(x)]₊。

## 理论框架

### 1. 预测准确性与决策质量：Theorems 1–3

- **Theorem 1：** R² 既非充分条件，也非必要条件。可以构造 R² 接近 1、但代理冠军是最差候选的例子；也可以构造 R² 任意负、但代理冠军恰好是真实最优者的例子。
- **Theorem 2：** 两个代理可以有相同均方误差（Mean Squared Error，MSE），但一个选出真实最优候选，另一个选出最差候选。差异集中在过度预测误差的上尾。
- **Theorem 3：选择税（selection tax）。** 若预测误差均值为零且为尺度 σ 的次高斯变量，筛选 N 个候选后，冠军位置的期望过度预测满足：

$$
\mathbb E[e^+(\hat x)]\leq 2\sigma\sqrt{\ln N}
$$

作者给出独立高斯误差实例的匹配数量级下界，说明即使代理整体无偏，扩大筛选规模也会放大最终冠军位置的乐观偏差。

### 2. 分离原则：提案与认证：Theorems 4–5

论文把搜索分成两条信息通道：**提案（proposal）**负责决定下一步尝试什么、训练代理模型和生成候选；**认证（certification）**负责淘汰候选、决定停止、报告数值和给出统计保证。

**Theorem 4：认证不变性。** 只要置信区间、候选淘汰规则、停止规则和最终报告完全由 Oracle 评估计算，提案端就可以不受限制地使用代理，甚至用任意偏差的伪标签重新训练。以至少 1−δ 的概率，所有认证结论仍正确；代理错误可能浪费预算，但不能污染认证证书。

**Theorem 5：被污染的认证可能确定性失败。** 若把伪标签与真实观测等同对待，存在只有两个候选的任务，使系统在零次真实 Oracle 调用的情况下，以概率 1 认证错误候选。这是模型用自己的错误预测给自己提供证据的自我确认（self-confirmation）失败。

作者禁止的是把未经校准的预测当作真实测量直接纳入认证，并非禁止所有模型辅助认证；经 Oracle 标签校准且有有效覆盖保证的预测辅助方法仍可能成立。

### 3. 认证搜索成本：Theorems 6–7

**Theorem 6：** 噪声尺度为 σ、候选与最优值差距为 Δx 时，认证淘汰该候选所需评估次数量级为 O(σ²Δx⁻² log(N/δ))。接近最优的候选需要更精细的真实评估。

**Theorem 7：** 若距最优值不超过 u 的候选数量满足 margin 条件 # {x:0<Δx≤u} ≤ NC u^α，则认证精度 ε 的总成本在 α<2 时按 ε^{-(2−α)} 增长，在 α=2 时按 log(1/ε) 增长，在 α>2 时与 ε 无关。认证成本取决于近优候选的密度。

### 4. 代理充当 Oracle：排序、审计与许可证：Theorems 8–11、13–14

**Theorem 8：排序保持（rank preservation）是最小条件。** 对任意候选池，代理选择遗憾不超过 ε，当且仅当它不会反转真实差距超过 ε 的候选对：

$$
f(x)-f(y)>\epsilon\Rightarrow\hat f(x)>\hat f(y)
$$

代理数值预测不必完全准确，但重要候选对的排序必须正确。

**Theorem 9：** 逐个验证某个争议比较，最坏情况下需要与直接用 Oracle 解决该比较相当的成本；信任应通过审计在多个后续决策间摊销。

**Theorem 10：审计与部署差距。** 令 p 为随机候选中过度预测超过容忍值 τ 的比例，部署从 N 个候选中按代理选冠军。冠军发生此类错误的概率 q 满足 q≤1−(1−p)^N≤Np，且最坏情况下为 Θ(min(1,Np))。被动随机审计需 Ω(N/ρ) 次 Oracle 查询才能保证部署失败率不超过 ρ。选择感知审计直接模拟部署：抽取候选池、代理选冠军、Oracle 验证冠军；其查询量为 O(ρ⁻¹log(1/δ))。

**Theorem 11：单侧许可证（one-sided license）。** 若审计认证过度预测超过 τ 的候选比例至多为 p，则以至少 1−Np 的概率，部署候选满足 f(x̂)≥f̂(x̂)−τ。这是价值下界保证（no-disappointment guarantee），不等于证明代理选择接近全局最优。许可证绑定具体模型与候选分布；重新训练或分布漂移后必须重新审计。

**Theorem 13：** 成对反转审计 qinv 的部署盲区为 Θ(N²)，冠军审计 qsel 的盲区为 Θ(N)。两种审计每轮需要两个 Oracle 调用；同等遗憾目标下，冠军审计具有约 N 倍的审计优势。

**Theorem 14：** 对任意自适应、随机化且了解代理和候选分布的审计设计，若要认证部署选择失败率低于 ρ0，且在安全实例上仍有至少一半机会通过，最坏情况下仍需 Ω(N/ρ0) 次 Oracle 查询；冠军审计在该类排序 / 遗憾保证上达到最优查询复杂度（差一个置信参数的对数因子）。

**Remark 15：** qsel 是保守统计量，即使代理是完美排序器、真实遗憾为零，qsel 仍可能为正。若有穷尽真实标签，应同时报告直接部署失败率和审计证书；证书无法通过只说明当前统计量没有颁发许可证，不能据此断言不存在安全选择器。

### 5. 经济性二分：Theorem 12

- **固定菜单选择：** 在候选之间没有共享结构的 tabular 模型中，认证给定菜单的最优者不能靠伪标签减少 Oracle 成本；每个候选都需要真实证据。此结论不直接适用于线性或 RKHS 等结构化候选类。
- **生成式搜索：** 若从候选分布抽到达标设计的概率为 pv，Oracle-only 方法每个认证设计需要 Ω(1/pv) 次评估。代理若通过选择感知审计，可筛选 M 个候选并只真实验证冠军；摊销训练与审计后，理论成本分离量级为 Θ(M/log(1/ρ))。优势以审计通过为条件。

## 实验设计

作者使用三个可以穷尽真实结果的任务：

| 任务 | 候选空间 | Oracle / 目标 |
| --- | ---: | --- |
| HPO-GBM | 1,152 个梯度提升回归器超参数配置 | Diabetes 数据集上的真实训练，三折交叉验证表现 |
| HPO-SVM | 576 个支持向量分类器超参数配置 | Breast Cancer 数据集上的真实训练，三折交叉验证表现 |
| NAS-Bench-201 | 15,625 个卷积网络 cell 架构 | CIFAR-10 验证准确率作为搜索目标，另报告选中架构的测试准确率 |

共 17,353 个真实训练结果。任务 1–2 的容忍度 ε=τ 设为目标范围的 5%；NAS-Bench-201 设为 2 个准确率百分点。

代理模型包括随机森林、极端随机树、梯度提升、k 近邻、岭回归和 0.2 分位数保守梯度提升。训练规模：任务 1–2 为 40–160 个标签，NAS-Bench-201 为 100–400 个标签。训练数据分为 Representative（整体分布均匀抽样）与 Biased（仅从真实性能低于中位数的一半区域抽样）两种条件。

部署池大小 N∈{3,10,30,100,300,1000}，每个条件运行 3,000–6,000 个重复候选池。作者还比较随机提案、代表性数据训练的随机森林、偏置数据训练的 Ridge，以及完全信任代理而不验证四种提案策略。推荐闭环共享 40 次真实 Oracle 预热，每种策略运行 20 个随机种子。筛选实验以 M=100 为一批，只真实验证代理选出的冠军。

## 实验结果

### 1. 选择税与拟合级风险

Task 1 中，10 个 Ridge 拟合的被动审计过度预测率都在 0.28–0.33，但在 N=1000 部署时，4 个拟合失败率接近 1，5 个低于 0.01，另一个约为 0.13。Task 2 中两个 Ridge 拟合审计率为 0.247 和 0.252，N=1000 部署失败率却分别为 0 和 1。Task 3 中 Ridge 在 N=100 时失败率约 95%，N=1000 时达到 100%。风险取决于具体拟合、任务和数据条件，不能从模型类别或训练配方推断。

### 2. 审计统计量与部署遗憾

作者在三任务、两数据条件下共评估 432 次代理拟合。qsel、qinv 和 R² 与 N=100 部署遗憾的 Spearman 相关系数如下：

| 任务与条件 | qsel | qinv | R² |
| --- | ---: | ---: | ---: |
| HPO-GBM / 代表性 | 0.96 | 0.86 | 0.80 |
| HPO-GBM / 偏置 | 0.99 | 0.78 | 0.76 |
| HPO-SVM / 代表性 | 0.89 | 0.68 | 0.59 |
| HPO-SVM / 偏置 | 0.89 | 0.68 | 0.64 |
| NAS-Bench-201 / 代表性 | 0.96 | 0.77 | 0.38 |
| NAS-Bench-201 / 偏置 | 0.97 | 0.56 | 0.33 |

充分测量预算下，qsel 相关性为 0.89–0.99；实际 120 轮、每轮两个 Oracle 调用的审计预算下为 0.80–0.94。HPO-SVM 中有 24.8% 候选落在 ε 近优区，遗憾被压缩，排序诊断的相关性也会减弱。

### 3. 许可证与分布漂移

同一保守分位数模型配方的不同拟合可能一例通过、一例失败：Task 2 中审计率 0.090 的拟合部署良好；审计率 0.116 的拟合在 N=100 时有 30% 违反率。NAS-Bench-201 目标从 CIFAR-10 漂移到 CIFAR-100 和 ImageNet16-120 后，作者重新审计；12 个原目标许可证和 24 个漂移后许可证均满足设定上限。候选分布漂移实验中，48 个重新审计的许可证全部恢复有效。作者据此强调，许可证必须针对具体拟合和当前分布。

### 4. 推荐与筛选的成本收益

Task 1 推荐闭环中，代理引导提案达到同等真实推荐质量需 94 次 Oracle 评估，随机提案需 204 次，约节省 2.2 倍。偏置代理早期提案可能不如随机搜索，但只要推荐值来自真实 Oracle 评估，推荐有效性仍不受提案质量影响。取消验证、直接相信偏置代理时，模型宣称目标值 0.43，真实结果只有 0.34，预测与交付差距为目标范围的 22%，真实遗憾为目标范围的 38%。

在 M=100 的筛选设置下，经审计筛选在 NAS-Bench-201 上减少约 25 倍 Oracle 评估，在 Task 1 上约 33 倍；NAS-Bench-201 冠军平均测试准确率 87.1%，全局最优为 89.2%。这些倍数在摊销训练标签与审计成本后计算。若将 200 个训练标签和 120 轮审计的 240 次 Oracle 调用全部计入，一次 100 个设计活动仍约节省 14 倍；25 个设计约节省 6 倍，1,000 个设计约节省 23 倍，规模增大时趋近 25 倍。基线是无辅助结构的 Oracle-only 随机抽样，并非所有可能的真实评估搜索算法。

### 5. 训练标签与审计预算

论文将每次 Oracle 调用视为购买两种资源之一：训练标签改善选择器、降低部署反转率；审计轮次不改善模型本身，但为选择器提供认证。审计成本存在不可绕过的最低门槛。

在作者构造的困难景观上，纯粹利用代理预测、只给最高预测候选打标签的 exploit-top 策略，比均匀采样需要约 3 倍训练标签才能获得同一许可证；均匀采样和不确定性采样更便宜。作者解释，许可证要衡量整个顶部排序是否可靠，只追逐当前预测冠军无法证伪被忽略的区域，可能陷入诱饵峰（decoy lock-in）。

在一个 ρ=0.10 的预算例子中，均匀采样获得许可证需要 600 个训练标签加 6,742 次审计 Oracle 调用，总计 7,342；exploit-top 需要 1,800 个训练标签加同样的 6,742 次审计调用，总计 8,542。

### 6. 许可证为被选位置的误差定价

作者通过人工制造代理过度预测，研究模型错误的比例与幅度如何影响许可证。实验发现，在测试范围内，小于容忍值 ε 的过度预测即使出现在较大比例的候选上，也不一定损害许可证；许可证边界主要取决于被选择位置的误差幅度，而不是简单统计多少标签预测正确。

许可证失效后，按预测值从高到低优先修正候选，只需约 50–530 次真实修正即可恢复许可证；随机挑选修正对象，在测试预算 6,400 次内都未能恢复。针对高预测值候选进行验证，既是审计手段，也是有效的修复策略。

## 作者给出的实践准则

论文第 4.7 节将理论和实验归纳为四条操作原则：

1. **Train on anything：** 提案、模型训练和伪标签使用不受认证规则限制。
2. **Certify only with clean oracle statistics：** 最终报告的值和认证结论必须有真实评估依据；R² 可作为模型开发诊断，但不能作为部署信任证书。
3. **Audit where the search actually points：** 在让代理充当选择器前，针对计划中的候选池规模运行冠军审计，并根据所需保证选择相应许可证。
4. **Re-audit when anything moves：** 模型重新训练或候选生成分布发生漂移时，原许可证失效，应重新审计。

当报告值本身比发现速度更重要时，作者建议优先考虑单侧保守价值许可证；如果需要保证选择遗憾，则必须使用更严格、成本更高的排序审计。

## 局限与开放问题

- **理论适用范围：** 主要保证针对单次决策的候选池选择和生成式搜索。有限个策略、控制器或提示的整体选择可视为候选池问题；但在策略学习过程中逐步归因和认证每次策略改进、且模型误差会跨时间累积的情形仍未解决。
- **结构化候选类：** 固定菜单的“每个候选至少需要真实证据”结论针对无共享结构的 tabular 模型。在线性或 RKHS 等结构化模型中，能否在认证遗憾的同时严格节省真实评估成本，是作者指出的主要开放问题。
- **价值证书不等于遗憾证书：** 生成式筛选的严格成本优势认证的是一个价值门槛，而不是对全局最优遗憾的保证。
- **审计统计量可能保守：** Remark 15 指出 qsel 对完美选择器也可能为正；穷尽真实标签时应同时报告直接部署失败率，不能把证书无法通过误读为选择器必然不安全。
- **成本优势有条件：** 只有审计通过、且任务属于论文证明的生成式质量门槛场景时，才能获得相应成本分离；论文没有声称所有代理搜索都无条件加速。
- **实验覆盖范围：** 三个任务包括两个超参数优化空间和一个神经架构基准，不能据此断言所有科学实验、材料设计或其他代理任务具有相同数值收益。

## 与相关工作的关系

以下关系按论文的相关工作讨论归纳，不代表这些工作已被本文实验直接组合：

- **Optimizer's Curse（优化器诅咒）与 winner's curse（赢家诅咒）：** 解释为什么在大量候选中选择预测最大值，会导致所选结果系统性乐观。本文将这一现象放入代理部署与审计框架，并给出选择税的上下界。
- **Offline Model-Based Optimization（离线模型驱动优化）：** 代理在有限、可能有偏的训练数据上学习，再向高性能区域外推。本文关注外推误差在 argmax 选择时如何放大，以及如何对具体部署模型审计。
- **Conformal Selection / Selection-Conditional Conformal Prediction（选择条件保形推断）：** 既有方法可在交换性等条件下提供选择后的覆盖保证。作者指出，在这些条件成立时，相关工具可能比本文较一般的许可证更精细；本文重点是以部署模拟审计构造较少依赖模型形式假设的保证。
- **Multi-Fidelity Gaussian Process / Proxy-Assisted Bandits（多保真高斯过程与代理辅助老虎机）：** 部分既有方法假设廉价代理与真实 Oracle 之间存在已知偏差界或相关结构；本文则把代理部署质量作为需要测量、审计并定价的对象。

## 核心结论

本文将“代理模型是否足够好”从全局拟合指标问题，改写为与具体部署行为绑定的认证问题：

- 高 R² 和低 MSE 都不能单独保证代理选出的候选可靠；选择会放大误差上尾。
- 代理可以自由参与提案和训练，但未经 Oracle 校准的预测不能作为认证数据。
- 代理充当选择 Oracle 的核心条件是重要候选对的排序保持，而非数值预测完全准确。
- 审计必须模拟实际部署选择；被动随机审计可能漏掉冠军处的错误。
- 许可证绑定具体模型与候选分布，重新训练或分布漂移后需要重新审计。
- 代理成本优势取决于目标：无结构固定菜单的最优性认证不能靠伪标签减少 Oracle 成本；生成式搜索寻找达标设计则可能在审计通过后显著降低每个认证设计的成本。
