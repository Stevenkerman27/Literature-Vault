> [!abstract] 摘要直译
> 在气动外形优化中，高保真（High-Fidelity，HF）仿真通常更准确，但也比低保真（Low-Fidelity，LF）仿真更耗时。为同时利用 HF 与 LF 仿真，本文提出了结合迁移学习的多保真卷积神经网络（Multi-Fidelity Convolutional Neural Network with Transfer Learning，MFCNN-TL）代理模型；它通过微调融合不同保真度的信息，并自适应地学习它们之间的非线性映射。该代理模型给出了一种新的优化框架，将形状参数与气动性能之间的关系映射出来。在该框架中，分别采用细网格 HF 模型和粗网格 LF 模型。每次优化迭代均采用多保真加点策略，新增 HF 与 LF 样本来更新代理模型。最后，将该方法应用于 NACA0012 翼型和 RAE2822 翼型的气动外形优化。优化结果表明，与单保真代理模型相比，所提出的 MFCNN-TL 能显著降低计算成本并提高优化效率。

## 问题与动机

气动外形优化需要反复调用 CFD 来评估候选几何。若始终使用细网格，代理模型的训练数据质量高但成本难以承受；若只使用粗网格，虽然覆盖设计空间便宜，模型却会继承粗网格对激波、黏性和边界层的系统误差。传统多保真协同克里金通常假定不同保真度之间存在线性或预先指定的桥接关系，而将低保真和高保真数据直接交给全连接神经网络，又会带来参数过多、特征提取不充分和小样本训练不稳的问题。

作者的核心判断是：LF 与 HF 的关系不必拆成显式的线性映射与非线性残差映射。可先让卷积神经网络（Convolutional Neural Network，CNN）从大量廉价 LF 翼型中学习“形状图像到气动系数”的通用特征，再用少量 HF 样本只调整网络后部，使输出尺度和局部规律贴近细网格结果。由此把 HF 的计算预算集中到校正阶段，并把代理模型置于迭代优化循环中。

## 方法

### MFCNN-TL：先低保真预训练，再高保真微调

![[assets/mfcnn-transfer-learning/mfcnn-tl-architecture-p005.png]]

*图 2，MFCNN-TL 的迁移流程：LF 的 CFD 数据训练源任务；卷积与池化等前部特征层被固定，再以 HF 数据微调后部全连接层和输出层，得到目标任务。*

整个流程分为三步。

1. **建立两种保真度数据集。** 对同一组由拉丁超立方抽样（Latin Hypercube Sampling，LHS）生成的翼型参数，分别以粗、细网格运行 CFD；LF 样本数量为 $m$，HF 样本数量为 $n$，且 $m \gg n$。
2. **LF 预训练。** 以 LF 数据训练完整 CNN，Adam 优化器学习从翼型图像到三个气动系数的映射。所得权重将粗网格虽有偏差、但覆盖较广的几何-气动规律压缩为特征提取器。
3. **HF 微调。** 固定网络前若干层，以较小学习率仅重训最后两层的权重和偏置。论文把这些层视作与最终气动标定最相关的部分；HF 样本因而不必从零开始学习几何特征，而是负责校正 LF 到 HF 的非线性差异。

这种做法没有显式写出 $y_{HF}=f(y_{LF})$ 的公式；LF 信息通过初始化参数进入模型，HF 通过微调改变其后段表示。因此它可以表达非线性保真度差异，但前提是两种网格下的翼型响应在主要特征上仍有关联。若 LF 对关键流动机制给出错误拓扑，迁移学习本身并不能保证修正。

### 输入、网络与多任务输出

每个翼型被光栅化为 $128\times128$ 灰度图，而不是直接输入 B 样条控制点。浅层网络采用四个并行的 Sobel 检测器，分别捕捉水平、竖直和两个对角方向的局部边缘；第二卷积层从这些基础线条组合出厚度、相对拱高、曲率和切线方向等几何表征。随后经池化、全连接层和两个各含 1024 个神经元的隐藏层拟合响应；隐藏层使用参数化修正线性单元（Parametric Rectified Linear Unit，PReLU）激活函数，负半轴斜率设为 0.1。

输出端不为 $C_l$、$C_d$、$C_{m,c/4}$ 分别训练三个网络，而是采用多任务学习（Multi-Task Learning，MTL）：底层表征共享，三个系数的误差共同反向传播。损失以每项的均方误差（Mean Squared Error，MSE）为基础，并引入可学习的任务噪声标量进行加权；误差较大或噪声较高的任务不会机械地主导所有梯度。这样可利用升力、阻力、力矩均由同一翼型几何和流场产生的相关性。

论文在叙述中先称卷积后使用最大池化，随后逐层规格又明确两处均为均值池化（第一层 $2\times2$、步长 1；第二层 $2\times2$、步长 2）。后者给出了具体尺寸，较可能是实际实现，但文中存在不一致，复现时应以代码或作者确认的配置为准。

### 优化循环与多保真加点

翼型的上下表面分别由 B 样条曲线表示。两端控制点固定在前缘 $(0,0)$ 和后缘 $(1,0)$，其余控制点沿弦向半余弦分布，只允许竖直移动。这使参数变化集中在外形弯度和厚度，而不会移动前、后缘。

每一轮以粒子群优化（Particle Swarm Optimization，PSO）搜索当前代理模型的最优几何，然后按两条不同规则补样：

- **HF 加样**：把当前代理模型预测的最优点直接做一次细网格 CFD，并加入 HF 数据库。这是开发型策略，意在迅速提高最可能改进区域的精度。
- **LF 加样**：在设计域中寻找与所有现有 HF 和 LF 样本的最小欧氏距离最大的点，即最大化 $\min_{x_i\in X}d(x_{new},x_i)$，并对该点做粗网格 CFD。它是空间填充式探索，避免低保真预训练数据只堆积在当前最优附近。

因此每轮固定加入 1 个 HF 点和 2 个 LF 点，重新训练/微调代理模型，再进入下一轮。需要注意，这个规则并未利用 CNN 的预测方差或预期改进（Expected Improvement，EI）等贝叶斯采集函数；HF 点由“当前最优”而非“最大不确定度”决定。它在目标函数比较平滑、模型最优附近可信时很高效，但可能错过模型尚未覆盖的狭窄流动突变区。

### CFD 与保真度定义

两种保真度只改变网格单元数，求解器和物理设置保持一致：二维稳态雷诺平均纳维-斯托克斯（Reynolds-Averaged Navier-Stokes，RANS）方程采用有限体积离散与耦合算法，空间离散为二阶迎风格式；湍流使用 Spalart-Allmaras（S-A）单方程模型。由此 LF 并非更简化的物理模型，而是同一 RANS 模型的粗网格解，偏差主要来自网格分辨率。

## 实验设置

### NACA0012：跨声速无黏阻力最小化

- **目标与约束**：自由来流马赫数 $Ma=0.85$、迎角 $0^\circ$；最小化阻力系数 $C_d$，约束升力系数 $C_l=0$，且设计翼型在全弦向不得低于基准翼型。
- **网格和成本**：HF 网格为 76,755 个单元，LF 网格为 7,080 个单元；初始 $C_d$ 分别为 472.9 与 458.05 drag counts（1 drag count 为 $10^{-4}$），对比参考单保真结果 472.2。单个 HF 计算约为 LF 的 7 倍耗时。
- **样本与循环**：初始为 20 个 HF、100 个 LF；每轮 1 HF + 2 LF，最多 75 轮。第 48 轮后阻力达到最小值，因此实际新增 48 个 HF 与 96 个 LF。

### RAE2822：跨声速黏性阻力最小化

- **目标与约束**：$Ma=0.734$、$C_l=0.824$、雷诺数 $Re=6.5\times10^6$；最小化 $C_d$，并要求俯仰力矩系数 $C_m\ge-0.092$。论文称对面积约束作了简化，但未在优化问题中明确给出数值形式。
- **网格和成本**：HF 为 76,750 个单元，LF 为 13,216 个单元；HF 的计算时间约为 LF 的 6.6 倍。细网格压力分布与实验更接近，是此处将其视为目标保真度的依据。
- **样本与循环**：同样以 20 HF + 100 LF 起步、每轮补 1 HF + 2 LF、上限 75 轮；第 41 轮收敛，故最终使用 61 个 HF 和 182 个 LF 样本。

NACA0012 的优化翼型后半段加厚、上表面中部变平，压力恢复段的强激波被削弱为较弱激波，说明其降阻主要来自波阻降低。RAE2822 的最优翼型前缘半径更小、最大厚度后移、下表面后半段更凹：前两者有利于降低摩擦和激波损失，后者补偿增厚引起的升力变化，使 $C_l$ 约束仍可满足。两组压力等值线都显示原始翼型上表面中后段的强激波在优化后消退或减弱。

论文结论称 NACA0012 的计算成本相对单保真降低 90.3%，该数字与表中 96/987 约为 9.7% 的 HF 等价成本一致；RAE2822 的成本降低 25%。这表明优势主要来自让大量 LF 样本承担形状特征学习，而不是减少优化轮数本身。

## 关键贡献

- 将多保真融合改写为迁移学习问题：LF CNN 负责特征预训练，HF 小样本负责后段微调，避免显式指定 LF-HF 线性桥接函数。
- 将翼型编码为灰度图并用 CNN 提取局部几何特征，使形状表示与气动预测模型端到端连接；三气动系数又通过 MTL 共享表示。
- 把代理、PSO 与双保真加点结合成闭环：HF 服务于当前最优设计，LF 服务于设计空间覆盖。
- 在一个无黏基准和一个黏性跨声速基准上给出量化成本收益，并展示了激波减弱的流动层面解释。

## 局限与启发

- **保真度差异较窄。** LF 和 HF 都是同一 RANS 求解器的不同网格，成本比例仅约 6.6--7；若 LF 改为欧拉、势流或经验模型，物理偏差更大，冻结的低层特征是否仍可迁移尚未验证。
- **缺少独立代理精度评估。** 论文展示最终优化量和压力分布，但没有为 $C_l$、$C_d$、$C_m$ 报告独立测试集误差、校准曲线或对不同 HF 初始样本的统计重复结果，因而难以拆分“迁移学习的贡献”和“加点规则的贡献”。
- **图像表示会引入分辨率限制。** $128\times128$ 灰度图可能丢失前缘半径、尾缘厚度或局部曲率的细节；几何参数本身已经是 B 样条控制点时，图像编码的优势应与直接点云/参数编码进行消融比较。
- **HF 加点偏开发。** 每轮只验证当前代理最优点，若早期 LF 预训练把搜索引向错误区域，策略不一定会主动探测远处的高误差区。工程上可与模型集合分歧、交叉验证误差或 EI 类不确定性采集函数混合。
- **复现信息不完整。** 冻结的具体层数、滤波器数量、训练轮数、学习率、图像栅格化细节和优化变量个数未在正文充分给出；池化描述也有矛盾。该工作更适合作为“迁移式多保真代理”的设计思路，而不是可直接照抄的网络配置。
