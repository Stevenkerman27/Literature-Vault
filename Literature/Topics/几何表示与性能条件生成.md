# 几何表示与性能条件生成

> [!abstract] 核心问题
> 逆设计并非“唯一正确的几何答案”：同一目标性能可能由多个几何构型满足。要同时解决 **可表达性、连续条件精度、可行性与多样性**，必须先明确几何表示是截面参数、CAD 操作序列、潜变量还是整机混合离散/连续结构。

## 可证实的方法脉络

**直接：** [[Literature/PaDGAN - A Generative Adversarial Network for Performance Augmented Diverse Designs|PaDGAN]] → [[Literature/PcDGAN - A Continuous Conditional Diverse Generative Adversarial Network For Inverse Design|PcDGAN]]，但后者不仅“加一个条件输入”，还处理连续标签不平衡、singular vicinal sampling 与误差到条件质量的映射。详见 [[Literature/PaDGAN 与 PcDGAN：关系、差异与选择|两篇的完整对照]]。

**对比：** [[Literature/DiffAirfoil An Efficient Novel Airfoil Sampler Based on Latent Space Diffusion Model for Aerodynamic Shape Optimization|DiffAirfoil]] ↔ [[Literature/PcDGAN - A Continuous Conditional Diverse Generative Adversarial Network For Inverse Design|PcDGAN]]。一个更强调潜空间去噪引导与几何流形，一个更强调连续条件下判别训练和 DPP；无论文证明可直接无损替换。

**语义拆分：** [[Literature/transformer/SkexGen - Autoregressive Generation of CAD Construction Sequences with Disentangled Codebooks|SkexGen]] 把 CAD 拓扑与几何的潜码区分，可启发整机分部件/连接关系生成；但机翼连续 CST 截面序列不等同于 CAD 离散操作命令。

## 对连续变长截面 Transformer 的具体启发（项目假设）

- **先选表示，再选概率头**：用 EOS 控制截面数、连续参数分布用 Gaussian Mixture Model（GMM，高斯混合模型）建模时，GMM-NLL（负对数似然）处理连续输出一对多；它**不负责**保证结构可行或高性能。
- **全局和局部解耦**：先预测跨度、面积、总体布局等全局量，再依据共享上下文解码变长截面序列；这只是架构选择，不一定需要另加 CVAE 或 diffusion。
- **多样性目标单独定义**：将 [[Literature/PaDGAN - A Generative Adversarial Network for Performance Augmented Diverse Designs|PaDGAN]] / [[Literature/PcDGAN - A Continuous Conditional Diverse Generative Adversarial Network For Inverse Design|PcDGAN]] 的 DPP 思路用于批内候选，可选择物理意义明确的几何距离或可验证的 latent 距离。需要确认“不同”不是单纯尺寸变化或不可行样本增加。
- **连续需求**：升力、最小速度、载荷因子、最大翼重与展向包络构成条件向量；用物理代理检验 feasibility（可行性），而不是把连续条件 NLL 当作约束满足的替代指标。

相关模型输出与可微物理链在 [[Literature/Topics/机翼生成器研究对照与证据边界|机翼生成器研究对照]]。


## 区间条件生成：Range-GAN

[[Literature/Range-GAN Range-Constrained Generative Adversarial Network for Conditioned Design Synthesis|Range-GAN]] 将条件从单一目标值扩展为可接受区间，分别用 range loss、uniformity loss 和 label-aware self-augmentation 处理可行性、区间覆盖和标签稀疏。该方法可迁移到气动/结构性能约束，但原论文飞机案例并未直接约束气动性能，也未解决跨布局拓扑生成。
