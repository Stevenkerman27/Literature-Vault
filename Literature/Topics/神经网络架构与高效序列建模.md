# 神经网络架构与高效序列建模

> [!abstract] 阅读导航
> 本专题按**跨 token 信息传播机制**而不是“名称中是否有 Transformer”来组织模型：标准/稀疏注意力、线性注意力/矩阵记忆、状态空间模型（SSM）、长卷积、动态权重，以及视觉/物理混合网络。注意**直接继承**、**数学对偶**、**机制类似**与**项目假设**并不等同。

### 四个经常混淆的“线性”

- **线性注意力**：因式分解相似度核或交换 KV 聚合顺序，不显式生成所有 token 对的 Softmax 矩阵。
- **线性 SSM**：对隐藏状态的更新是线性的，但状态系数可能是当前输入的非线性函数；整个模型并非线性函数。
- **线性序列成本**：当状态、slice、专家数等固定时，随长度 N 呈线性；不代表随通道宽度、状态维数也线性。
- **神经算子**：讨论函数空间映射或积分核，与以上三项关于序列算法效率的说法不同。

### 2.1 已得到论文支持的三条脉络

1. **S4 → Mamba → Mamba-2/SSD → Mamba-3**：从 LTI 的卷积式 SSM，到输入选择性更新，再到结构化矩阵对偶与高速矩阵化，最后到指数调整梯形离散化、复数状态和 MIMO。它是一条真正的 Mamba 技术演进路线。
2. **RetNet / GLA + Delta Rule → Gated DeltaNet**：从衰减记忆到随输入变化的遗忘门控，再到按 Key 定位的修正写入。GLA 与 RetNet 有理论/机制延展，不能简单称为官方 v2。
3. **Transolver → LinearNO / NoTokenAttn 消融**：针对物理点云全局 slice 混合，后续实证说明 slice token 间自注意力不总是关键；**删除它不等于删除全局通信**。

### 2.2 不应混称“相同原理”的联系

- [[Literature/architectures/Transformers are SSMs Generalized Models and Efficient Algorithms Through Structured State Space Duality|SSD]] 只与某类有限维特征映射的结构化 Masked Attention 对偶，**没有证明所有 Softmax Attention = Mamba**。
- [[Literature/transformer/Mixture-of-Top-k Attention Efficient Attention via Scalable Fast Weights|MiTA]] 将历史压缩摘要与少量精确 KV 检索结合；[[Literature/transformer/Linear-Time Global Visual Modeling without Explicit Attention|WeightFormer]] 用全局统计生成动态层权重。两者共享 Fast-Weight MLP 解释，但一个保留 Attention，一个换掉显式 Attention。
- [[Literature/architectures/Hyena Hierarchy Towards Larger Convolutional Language Models|Hyena]] 是隐式长卷积 + 门控；S4 是 SSM 的时不变卷积表示；Mamba 使用时变的选择性状态更新。三者不能仅因“长序列/无 Attention”而归为同一模型。
- [[Literature/architectures/MambaVision A Hybrid Mamba-Transformer Vision Backbone|MambaVision]] 使用卷积和高层 Attention，是 2D 图像问题的混合网络。[[Literature/transformer/Spatially-aware transformer operator for real-time aerodynamic evaluations of arbitrary three-dimensional vehicles|SATO]] 也重视局部+全局，但针对 CFD 数据；二者属于**跨域类比**，不是直接模型继承。

## 4. 哪一类模型适合什么任务？

| 判断维度 | Attention / MiTA | SSM / Mamba / GDN | 物理 slice / Neural Operator |
|---|---|---|---|
| 序列是否有天然时间顺序 | 可以有，也可以没有 | 通常需要；扫描顺序影响结果 | 空间点集可无序，但需验证具体实现 |
| 是否保留对原始过去 token 的直接访问 | 全 Attention 是；MiTA 对选定 KV 是 | 固定状态通常不能 | 通过压缩 slice 读取历史/全局概括 |
| 训练 / 推理成本的主要限制 | Query–Key 数量、KV cache、路由访存 | 状态维度、scan、矩阵带宽 | 点数×slice、局部空间特征与全分辨率 FFN |
| 是否直接有 CFD/神经算子实证 | 本专题的通用模型多无 | 本专题的通用模型多无 | Transolver/LinearNO/SATO 具有对应领域实证 |

## 5. 迁移到翼面或整机 CFD 的证据边界

> [!warning] 项目假设，非原论文验证的结论
> 任意排列的非结构 CFD 面元不能直接被视为语言序列。SSM/Hyena 的一维扫描会引入点顺序偏置；用于空间算子需额外定义物理有意义的坐标、邻接、面积/体积积分权重，且验证节点重排、网格密度迁移与局部高频误差。

可执行的公平对照应保持几何与工况输入、数据划分、预测场、训练预算、参数规模和随机种子一致，并至少检查：局部 \(C_p\) / 剪切误差、积分 \(C_L,C_D,C_M\)、几何梯度、跨分辨率和 OOD、训练时间及 GPU 显存。线性复杂度或语言 perplexity 不能替代这些物理指标。

## 6. 还有哪些尚未形成独立笔记的空缺？

- FlashAttention / FlashAttention-2：原算法的 IO 优化，不应归类为改变函数表达的模型替代。
- RWKV、原始 DeltaNet、Native Sparse Attention、MoBA：矩阵记忆与硬件对齐路由的上游。
- VMamba、Vision Mamba、VSSD：二维扫描、非因果/无序视觉状态混合。
- Mamba/SSM 应用于真实 PDE 网格的系统性对照：需要严格区分时间算子与稳态空间场。

不对这些缺失论文伪造已存在的 Obsidian 链接；补齐前先从本页的已读原始论文出发。
