# Deformation-driven shape correspondence via shape recognition

> [!abstract] 摘要直译
> 许多形状比较和识别方法都从建立形状对应开始。我们“反其道而行”，表明通过执行大量形状识别任务可以获得高质量的形状对应。更进一步，所提出的方法能够计算两个 3D 形状之间细粒度、拓扑可变的部件对应，而其核心评价机制仅在全局尺度上识别形状。这通过将部件对应问题置于一个变形驱动的框架中，并依赖一种数据驱动的“变形能量”得以实现；该能量对变形后形状与形状库中模型之间的视觉相似度进行评分。我们的基本前提是：若两个椅子（或飞机、自行车等）之间的对应是正确的，那么以该对应为锚点的合理变形应产生可信的、具有“椅子特征”的中间形状。给定属于同一类别的两个 3D 形状，我们对部件对应进行自顶向下的层次化搜索。对于搜索层次中的每个候选对应，我们在遵守该对应的同时将一个输入形状变形为另一个，并依据所得变形形状与 ShapeNet 中同类别模型的相似程度为该对应评分。这种相似性，即合理性，通过比较多视图深度图像在为各类形状学习得到的类别特定特征上的表示来度量。我们在具有丰富几何和拓扑变化的大规模人造模型测试集上验证，相比现有方法取得了明确改进。

## 问题与动机

目标是在同一类别、但几何、部件组织和拓扑均可能显著不同的两个 3D 人造物体之间，建立细粒度部件对应。这里的“对应”并不局限于一一匹配：例如一个形状中的多个支撑件可以共同对应另一形状中的一个支撑结构，也允许某些非必要部件不匹配。

传统方法多以局部几何相似度、结构规则或人工设计的变形能量评价候选匹配。当对象差异较大时，纯几何度量难以辨别语义上正确的匹配；监督方法虽可利用语义先验，却需要昂贵的细粒度部件标签和精心设计的特征空间。GeoTopo 等变形驱动方法可以处理拓扑变化，但其用于保持结构的变形能量同时也被用来评价对应，因而可能出现“错误对应在结构保持约束下仍很容易变形”的误判。

论文提出反向思路：不训练部件类别，也不直接学习对应，而是检验候选对应所诱导的中间形状是否符合该类别的形状分布。若将一把椅子的某些部件替换为另一把椅子的对应部件后，经过局部结构恢复得到的形状仍像椅子，则该对应可信；若产生缺少关键构件或具有不协调组合的形状，则应降低评分。由此，对应质量可由大量全局形状识别任务间接评估，所需人工知识仅为对象类别标签。

## 方法

![[assets/deformation-driven-shape-correspondence/method-overview-fig2.png]]

*图 2，方法总览：从两个预分割形状开始，算法反复二分子结构；每轮通过双向生成中间形状并以类别合理性评分选择匹配，直至获得最终部件对应。*

### 输入与预处理

- 输入：同类别的两个预分割或未分割 3D 人造物体。
- 对未分割对象进行基于近似凸性的过分割；输入已分割时直接使用其部件。
- 通过共层次结构分析检测反射和旋转对称性，并将对称部件组成一个节点。这样可避免分别匹配本应成组出现的部件。
- 将每个对象表示为无向连通图：节点为对称部件组，边表示两个部件组之间的物理连接。后续搜索只考虑能将图划分为两个连通子图的二分，因此候选仍保持可解释的结构子物体。

### 数据驱动的合理性评分

作者从 ShapeNet 中收集同类别模型，并在三个规范视角（正视、左视、俯视）渲染 224 x 224 的深度图。该设计假设所有模型均已具有一致的竖直方向和规范朝向；这是将三维结构合理性转为视觉判断的前提。对每个类别：

1. 在每个视图采样非空比例足够高的 56 x 56 patch，先进行 k-means 预聚类，再在簇中心上做自调节谱聚类。以类似 TF-IDF 的准则保留最具代表性且最有区分力的 60 个中层视觉元素。
2. 真实 ShapeNet 模型构成正样本；从深度图中随机删除部件构造“缺失关键子结构”负样本，随机交换部件构造“子结构组合错误”负样本。这两类负例对应错误匹配最常见的视觉后果。
3. 将中层元素作为 HOG 空间中的卷积滤波器，得到其在深度图上的响应图。沿横向和纵向分别将响应图分为五段并汇总，从而同时记录构件是否出现及其大致位置；所有元素的编码拼接为图像特征。
4. 用这些特征训练三分类 SVM：真实形状、缺失部件、错误组合。测试时，分类器给出的“真实形状”概率即单视图合理性；三个视图的最小值定义为一个形状的最终合理性，以惩罚只在特定视角暴露的结构错误。

该评分器还用于估计部件必要性。移除一个部件组后，若合理性下降超过 20%，该组被视为关键部件，搜索时不允许将其匹配为空；例如椅子的前腿通常关键，扶手可能不是。

### 层次化对应搜索

对两张部件连接图递归进行二分，并对每对二分候选考虑两种交叉匹配。设源、目标图各被分为两个连通子图，每种匹配并不直接比较部件形状，而以它诱导的中间形状评分：

1. 以目标对象中一个匹配子图替换源对象中的对应子图，反方向也执行一次。论文只评价每条变形路径中的一个部件替换状态，而不追踪完整连续变形轨迹，以控制计算量。
2. 替换会破坏原有连接和对称关系，因此对新部件做局部结构保持变形。其约束使相连部件之间的位移向量尽量不变，并分别维持每个对称组的对称关系。这个能量只负责产生可用的中间形状，不参与对应优劣评分。
3. 分别计算两个方向中间形状的合理性，候选对应的分数取两者较小值。取最小值要求对应在双向替换下都不产生明显失真的类别外形状。
4. 以自顶向下的 coarse-to-fine beam search 搜索匹配层次。每次扩展时仅保留得分最高的有限棵候选树，实验中 beam width 为 5；叶节点编码的匹配即为最终部件对应，回溯过程还给出与目标相关的层次分割。

搜索在以下情形停止细分：当前对应已是一对一或一对多且不可继续分解；进一步分解导致两方向中间形状的合理性明显下降；或连续层级的合理性变化落入容差，表明继续细化没有收益。该机制解释了为什么方法在输入细分不理想时可停在较粗但更可靠的粒度。搜索支持一对多、多对一以及一对空对应；后一种只允许分配给上述非关键部件。

## 关键贡献

1. 将细粒度、拓扑可变的形状对应转化为由类别级形状识别驱动的优化问题，展示了“识别可以反过来服务于对应”。
2. 仅依赖对象类别标签和同类模型库，不需要直接标注细粒度部件对应；知识库可直接来自 ShapeNet 一类已有仓库。
3. 以层次化图划分和 beam search 在可接受开销内探索大量对应结构，能够输出一对多、多对一和一对空匹配，也能适应目标相关的不同分割粒度。
4. 明确分离两类目标：局部变形能量用于保持中间形状的结构连续性，数据驱动合理性用于给候选对应排序，避免将“变形容易”误判为“对应正确”。

## 实验结果

实验覆盖椅子、桌子、床、飞机和自行车五类对象。定量比较使用 GeoTopo 基准中的 75 个模型，每类 15 个，因而每类有 105 对模型；两个方法都接收相同的初始分割。作者另请五位用户对每对模型直接制作细粒度、拓扑可变的部件对应，并以多数投票得到 ground truth，避免仅通过独立部件标签推断对应带来的歧义。

除自行车外，本文相对 GeoTopo 在 Precision / Recall 上均有明显提升：

| 类别 | GeoTopo | 本文方法 |
| --- | --- | --- |
| 椅子 | 0.69 / 0.67 | 0.83 / 0.83 |
| 桌子 | 0.63 / 0.61 | 0.81 / 0.86 |
| 床 | 0.60 / 0.62 | 0.78 / 0.81 |
| 飞机 | 0.60 / 0.68 | 0.80 / 0.85 |
| 自行车 | 0.47 / 0.44 | 0.43 / 0.49 |

定性结果还显示，GeoTopo 的自底向上一一匹配较难恢复多个部件对应一个较大结构的情况；本文的层次搜索可在父节点上保留这种群组对应。对于初始分割不完全一致的输入，进一步细分会使合理性下降，算法会在恰当的粗粒度处停止。

自行车没有获得优势，原因一是用于训练合理性评估器的 ShapeNet 自行车仅有 59 个模型，明显少于其他类别；原因二是车架、辐条等构件较细小，在深度图中不突出，导致全局视觉评分缺乏判别力。这也说明该方法的效果取决于知识库覆盖度和类别关键结构能否被多视图投影可靠呈现。

## 局限与启发

- **初始分割仍是边界条件**：层次搜索可以合并既有分割并在较粗尺度停止，但无法创造新的分割边界。因此，若真正的对应部件横跨初始分割，结果仍会受限。论文提出将分割和对应放入同一框架作为后续方向。
- **适用对象受限**：方法假设人造物体具有稳定的规范方向、离散部件结构和可保持的对称/邻接关系；其局部变形模型与规范视角深度图不适合有机形状的自由形变或关节运动。
- **合理性不等于功能性**：当前分数衡量视觉上是否“像椅子”或“像飞机”，不直接验证是否可坐、可支撑或可飞行。视觉上合理的中间形状仍可能来自不够准确的部件对应。
- **采样与搜索近似**：每条路径只选取一个中间状态来评价，且 beam width 限制了候选树数量；前者会对评分器噪声敏感，后者可能过早剪去正确分支。
- **知识库偏差**：训练集较小或类别内部差异没有被充分覆盖时，评估器不能可靠地区分合理和不合理结构。自行车结果正是这一问题的实证。

后续可用具有更强表征能力的多视图网络或类别条件生成模型替代中层元素加 SVM 的合理性评分，同时把分割、对应、功能约束和多中间状态的鲁棒聚合放进统一学习或优化框架。论文的更一般启发是：当直接监督目标昂贵时，可以利用数据分布中的“结果是否合理”来反向评价潜在结构关系。
