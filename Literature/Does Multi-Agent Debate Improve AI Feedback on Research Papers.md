> [!abstract] 摘要直译
> 至少对于经济学元分析而言，答案可能是否定的。在一项预注册、身份屏蔽、以论文为单位的实验中，44 篇元分析论文的作者对三份针对自己论文生成的 AI 报告按改进论文的有用程度排序：一份由前沿模型单次生成的报告，以及两份作者自行构建、原本预期会胜出的多智能体辩论工具生成的报告。所有报告统一为相同长度和模板。作者更偏好单次生成报告：相较 mad-research，平均排名优势为 0.66 个名次点（95% CI 0.32–1.00）；相较 paper-workshop，优势为 0.57 个名次点（95% CI 0.16–0.95），尽管 paper-workshop 消耗的 Token 约为前者的 30 倍。能够回忆期刊审稿意见的作者通常将真实审稿意见排在第一位，从未排在最后；而三位 AI 评委几乎总是把真实期刊审稿意见排在最后。在三份 AI 报告之间，Gemini（其模型家族没有参与生成任何报告）若代替作者评价，会把 paper-workshop 排在第一，从而反转作者对单次生成的偏好。这提醒我们不应以 AI 评委替代目标用户。本文测量的是作者对已完成论文反馈的感知有用性；是否应让 AI 担任期刊审稿人，是另一个独立问题。

## 核心结论

在 44 篇获得作者排名的经济学元分析论文中，作者显著更偏好 Single Pass；两种多智能体工具没有取得可检测的感知有用性增益，且成本明显更高。论文还说明评价者选择会改变结论：外部 AI 评委 Gemini 与作者排名一致性很弱，并会把最昂贵的 paper-workshop 排在第一。

**结论边界：** 这不是对所有 Multi-Agent Debate 的否定。实验只覆盖特定模型版本、特定工具实现、经济学元分析、固定长度报告和已完成论文；测量的是感知有用性，而非实际修改后的论文质量，也不是 AI 期刊审稿能力评估。

## 研究问题与动机

作者研究研究者在投稿前用 AI 获取第二意见的场景：一个强模型直接阅读论文是否已经足够？额外增加模型、角色、交叉批评和多轮讨论，能否让作者获得更有用的反馈？多智能体辩论的理论理由是不同模型可能发现彼此遗漏的问题，但既有研究结论并不一致。作者强调，论文反馈没有简单答案键，真正需要采取修改行动的论文作者才是直接的目标评价者。

作者选择经济学元分析，是因为研究方法相对标准化，纳入规则、发表偏差校正和统计模型等批评可以对照论文数据核查；这提高了可检验性，也限制了结论外推到其他论文类型的能力。

## 实验设计

### 样本

- 共 55 篇经济学元分析：作者自己的论文 27 篇，外部作者论文 28 篇；外部样本来自 Journal of Economic Surveys 自 2022 年 1 月以来符合条件的论文。
- 44 篇论文至少收到一份作者排名（80%）；共 66 份有效排名，来自 47 位作者。基线分析每篇论文只用第一份排名，即 44 个论文级观测；18 篇有多位排名者。
- 外部作者回应率 82%，作者自己的合作者回应率 78%；21 篇论文的作者还回忆并排序了真实期刊审稿意见。

### 三种配置

| 配置 | 模型与流程 | 调用数/论文 | Token/论文 |
| --- | --- | ---: | ---: |
| Single Pass | Claude Opus 4.8 单次调用，直接生成结构化报告 | 1 | 约 27,000 |
| mad-research | Claude Opus 4.8 与 GPT-5.5 独立审查、匿名交换批评，由新实例综合并保留少数意见 | 约 6 | 约 238,000 |
| paper-workshop（Act I） | Claude Opus 4.8 多 Agent 从不同专业视角审查、交叉质疑，评论关联原文并复核 | 约 10 | 约 800,000 |

paper-workshop 只运行轻量 desk-review 配置，没有测试完整的数十至数百 Agent 模式，也没有测试第二阶段自动生成 tracked-changes 修改稿的功能。报告于 2026 年 6 月下旬生成。

### 盲法与控制

三种配置读取同一篇论文，使用共同基础提示词；报告统一为摘要、主要意见、次要意见和总体评价，并缩短到约 1,000 词（Single Pass 平均 1,096 词，paper-workshop 约 1,070 词）。工具名称和识别性措辞被移除，展示顺序随机化。作者知道报告由 AI 生成，但不知道来自哪个工具。规范化可能改变意见强调程度或保留内容；研究于 2026 年 6 月 22 日在 Open Science Framework（OSF，开放科学框架）预注册。

作者按每篇论文内的有用性给三份报告排序，1 为最有用、3 为最不有用。主要分析使用论文内部排名差异、精确置换检验、Friedman 排名检验和按论文重采样的置信区间。

## 主要结果

### 作者排名

| 配置 | 平均排名（越低越好） | 排名第一比例 |
| --- | ---: | ---: |
| Single Pass | **1.59** | **55%** |
| mad-research | 2.25 | 18% |
| paper-workshop | 2.16 | 27% |

- 44 篇论文中，Single Pass 在 32 篇中优于 mad-research，在 30 篇中优于 paper-workshop。
- Single Pass 相较 mad-research 的排名差为 -0.66（95% CI：-1.00 至 -0.32，Holm 校正 p = 0.005）。
- Single Pass 相较 paper-workshop 的排名差为 -0.57（95% CI：-0.95 至 -0.16，Holm 校正 p = 0.026）。
- 两种多 Agent 工具之间无显著差异：0.09（95% CI：-0.32 至 0.50，p = 0.75）；三种方案总体排名不相等的精确置换检验 p = 0.0034。
- 作者自己的论文和外部论文排序一致，未发现样本分层与方案效果的交互差异（p = 0.97）。

### 计算成本

| 配置 | Token/论文 | API 等价成本/论文 |
| --- | ---: | ---: |
| Single Pass | 27,000 | $0.20 |
| mad-research | 238,000 | $1.87 |
| paper-workshop | 800,000 | $7.20 |

成本按 2026 年 7 月 API 标价折算；实际运行使用订阅计划，边际现金支出接近零。paper-workshop 消耗约 30 倍 Token、约 35 倍 API 等价成本，却没有获得更高作者排名。三种配置同时改变模型家族、提示和调用数量，因此这不是单独识别“增加 Agent 数量”因果效应的实验。

### 稳健性

使用每篇论文全部 66 份排名，Single Pass 仍领先（平均排名 1.60，Friedman 置换检验 p = 0.0012）。按排名者聚类、每位作者只保留一个排名、剔除预先标记的特殊论文、将近似平局改编码为平局，主要排序均未改变。即使假设 11 篇未回应论文全部偏好多 Agent，样本总体中 Single Pass 仍在多数论文上胜出。多位作者对同一论文的排名一致性较弱，说明个体偏好存在噪声；总体结论是跨论文的中心趋势。

## AI-as-a-Judge：评价者会改变结论

Gemini 是唯一没有参与生成报告的模型家族，其与作者排名的 Kendall 秩相关系数仅为 0.14（95% CI：-0.05 至 0.32）。Claude 和 GPT 与作者的相关系数分别为 0.20 和 0.27，但其模型家族参与了报告生成，存在自偏好风险。Gemini 将 paper-workshop 排在第一的比例为 64%，平均排名 1.45。若以 Gemini 代替作者评价，实验会得出“最复杂的多 Agent 工具最好”的相反结论。

### 人类期刊审稿意见对照

21 篇作者回忆真实期刊审稿意见的论文中，15 篇（71%）将其排在第一，0 篇排在最后。在另一项 26 篇作者自有论文的四选一 AI 评委实验中，Gemini、Claude、GPT 将人类审稿意见排在最后的比例分别为 100%、96%、92%。

两组数据并非同一批报告的同一评价协议：作者回忆整体期刊审稿反馈，AI 评委评价一份选定的人类报告；后者始终放在最后一个位置，且长度未与 AI 报告匹配。人类审稿意见针对修改前稿件，AI 报告针对已完成论文。因此该结果是评价者差异的描述性证据，不是人类审稿与 AI 审稿的严格优劣实验。

## 作者讨论与解释

1. **强基础模型可能降低辩论的边际收益。** 单个前沿模型已能在一次推理中完成较多自检；基础模型越强，第二个模型发现独立错误的空间可能越小。这是作者提出的解释，实验没有直接分离验证。
2. **讨论不等于信息增量。** 多个 Agent 可能重复发现相同问题；增加调用次数不保证出现新的、可操作的批评。
3. **固定长度可能压缩多 Agent 的潜在优势。** 讨论产生的细节和少数意见可能在统一报告长度时被压缩。
4. **感知有用性与实际改进不同。** 更严格深入的建议可能意味着更高修改成本；实验没有跟踪建议采纳率或修改后的论文质量。
5. **评价者必须是目标用户。** AI 评委可能偏好特定表达、长度或模型家族输出；本实验中 Gemini 的排序足以反转主结论。

## 局限与外推边界

- 仅研究经济学元分析，不能直接外推到新理论、复杂工程设计或代码调试。
- 外部样本来自单一期刊，且作者与样本学术网络较近；模型版本也固定在 2026 年 6 月。
- 三个方案同时改变模型家族、提示和调用数，无法将结果归因于 Agent 数量单一因素。
- paper-workshop 只测试轻量 Desk Review / Act I，未测试完整工作坊或 Act II 自动修改稿；统一报告长度也可能压缩多 Agent 的输出优势。
- 测量已完成论文的感知有用性，而非实际采纳、修改质量、研究产出或科学正确率。
- Gemini 使用较轻量的网页模型版本；“外部评委”与“较轻模型”在实验中混杂。AI 评委读取论文开头部分，作者则了解全文。
- 人类审稿比较中，作者回忆与 AI 四选一评价并非同一协议；人类报告长度和展示位置未控制。
- 作者开发了 mad-research 与 paper-workshop。预注册和盲化可降低偏差，但利益关系仍应纳入解读。

## 对 Multi-Agent 系统设计的启发

以下是结合论文结果形成的系统设计推论，不是论文直接验证的结论：

- **先建立强单 Agent 基线。** 否则无法判断增益来自更好的模型、更好的提示，还是多 Agent 协作机制。
- **用信息异质性定义 Agent 角色。** 不同角色应有不同专业职责、工具或证据来源，而不是只改角色名称后重复阅读相同材料。
- **把 Debate 用在有分歧的高价值问题上。** 先并行独立分析，再聚合意见，只对冲突、低置信度或高风险结论启动交叉质疑。
- **保留少数意见与证据链。** 共识不等于正确；反对意见应保留，批评应指向原文、数据、代码或可复现检查。
- **用目标用户和客观任务结果双重评价。** 记录新增问题、重复意见、验证通过率、建议采纳率、实际质量改进和 Token/时间成本，不以 Agent 数量或讨论轮数作为质量指标。

### 对 GRASS-plane 的潜在启发（项目假设，待验证）

1. 不应默认多个 Agent 对每个设计任务全程辩论。可先由单一强模型生成基线方案，再由几何、气动、结构/约束、实现审查等职责不同的 Agent 独立检查。
2. 只有当审查者发现相互冲突的物理判断、几何可行性问题或高风险实现问题时，才触发针对性 Debate；最终结论必须落到 DPanel 求解、数值检查或明确验收测试上。
3. 将“意见合理”“数值收敛”“物理精度通过”分开记录。语言模型的共识不能替代求解器验证。
4. 通过消融比较 Single-Agent、并行专家审查、全量 Debate、按需 Debate；控制基础模型、输入上下文和输出预算，记录有效新发现与计算成本。

以上是项目研究假说，本文没有在 GRASS-plane、DPanel 或飞机生成任务上进行实验。
