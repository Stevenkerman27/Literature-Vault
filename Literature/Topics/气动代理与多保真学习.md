# 气动代理与多保真学习

> [!abstract] 核心问题
> CFD 高保真数据稀缺且昂贵。需要同时回答 **用什么输入表示几何和工况**、**预测局部物理场还是整体系数**、**低/高保真如何融合**、**预测误差是否会让优化产生不可行解**。

## 多保真四种机制不能混称

1. [[Literature/Generation of surrogate-based aerodynamic model of an UCAV configuration using an adaptive co-Kriging method|Co-Kriging]]：通过统计相关性联合建模低/高保真响应，并按采样准则增添高保真点。
2. [[Literature/Multi-fidelity convolutional neural network surrogate model for aerodynamic optimization based on transfer learning|MFCNN-TL]]：利用可迁移网络表征，再用高保真数据调整权重。
3. [[Literature/Multi-fidelity aerodynamic data analysis by using composite neural network|Composite NN]]：通过网络组合学习跨保真映射。与“简单直接 fine-tune 同一个网络”有结构差异。
4. [[Literature/An ensemble weighted average conservative multi-fidelity surrogate modeling method for engineering optimization|保守多保真]]：并非另一个低/高保真融合 backbone，而是对代理在约束优化阶段的不确定性施加裕度。

[[Literature/Toward Accelerating Discovery via Physics-Driven and Interactive Multifidelity Bayesian Optimization|物理驱动的多保真贝叶斯优化]]则回答“**下一个昂贵样本应该在哪个位置和保真度获得？**”，与上述模型能互补，但其论文不等于已经把它们组合并验证。

## 局部量与积分量必须分别验证

[[Literature/transformer/Towards a Foundation-Model Paradigm for Aerodynamic Prediction in Three-dimensional Design|AeroTransformer]] 的笔记强调：由局部压力、摩擦应力以及网格法向/面积积分得到气动力，再对升阻力矩设置辅助损失，可以比只预测整体系数更贴近物理输出。但从低局部误差**不能自动推出**低积分误差，反之亦然。

对当前机翼任务：

- 先区分 $C_L$、$C_{D,i}$、$C_m$ 的无黏代理预测，与局部/粘性剖面阻力估计；不能用不可解析的“总阻力代理”混盖物理来源。
- 可微几何采样和 CFD 训练网格要分别验证**离散化一致性**，尤其是压力/面元载荷积分。
- 按几何族划分训练/验证，追加未见过的尺寸、升力需求和变长截面 OOD 测试；随机划分同一模板的参数邻域易高估泛化。
- 必须验证可微预测的梯度方向是否可用于优化（有限差分、真实仿真反馈），不只报告 $R^2$。
